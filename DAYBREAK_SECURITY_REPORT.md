## 3. Mathematical Verification of Scoped Attention & Open-Weight KV Controls

> [!NOTE]
> `Reference scoped-attention proof. Not integrated with Gemini internals or a production vLLM attention backend. No latency or isolation claim.`

`src/server/scoped-attention.ts` and `tests/unit/scoped-attention-exhaustive.test.ts` (`12 of 12` suites, `100%` passing under Vitest in IEEE-754 `float64`) verify four mathematical and structural properties required for Vervain's self-hosted open-weight engine roadmap (`vLLM`, `SGLang`, `Ollama`, `NVIDIA Dynamo`):

### 3.1 Pre-Max-Shift Score Masking Against Logit Underflow

For query $q \in \mathbb{R}^d$, physical paged pools $K_{\text{pool}}, V_{\text{pool}} \in \mathbb{R}^{P \times B \times d}$, block table $\pi \in \{0, \dots, P-1\}^M$, causal/slot mask $U \in \{0, 1\}^{M \times B}$, physical `uint32` scope array $\sigma_{\text{pool}}$, and server-derived request tag $\sigma_{\text{req}}$:

$$c_{b,s} = U_{b,s} \land \mathbf{1}\!\left[\sigma_{\text{pool}}[\pi_b] = \sigma_{\text{req}}\right], \qquad \tilde{x}_{b,s} = \begin{cases} \langle q, K_{\text{pool}}[\pi_b, s] \rangle / \sqrt{d}, & c_{b,s} = 1 \\ -\infty, & c_{b,s} = 0 \end{cases}$$

Applying $c_{b,s}$ **prior** to computing the softmax shift maximum $m^\star = \max_{(b,s): c_{b,s}=1} x_{b,s}$ prevents a hostile or high-norm foreign KV block (e.g., $+10^4$ logits while authorized logits sit at $-10^4$) from dominating $m^\star$ and underflowing $\exp(x_{\text{own}} - m^\star)$ to `0` in floating-point arithmetic. When active positions are empty ($\mathcal{A} = \emptyset$) or non-finite, `runReferencePagedAttention` fails closed with `refused_all_masked` and zero-filled finite vectors (`0` `NaN` values across `100%` of outputs).

### 3.2 `80 of 80` Seeded Online Block-Tiled `(m_i, l_i, O_i)` FlashAttention-2 Recurrence Sweep

Streaming tiled kernels (`FlashAttention-2` / `FlashInfer` paged decode) maintain running log-sum-exp statistics $(m^{(b)}, l^{(b)}, \tilde{O}^{(b)})$ across KV blocks without materializing the full score row. Using deterministic PRNG `mulberry32(0x5eedcafe)`, `tests/unit/scoped-attention-exhaustive.test.ts` swept **`80 of 80` seeded configurations** spanning:
- `9` head dimensions (`d` in `{1, 2, 3, 4, 8, 16, 32, 64, 128}`) and `7` block sizes (`B` in `{1, 2, 3, 4, 8, 16, 32}`),
- high-bit `uint32` boundaries (`0x80000001` vs `0x00000001`, `0xffffffff` vs `0x7fffffff`), partial tail masks, all-false blocks, repeated/permuted block tables, and zero-match `refused_all_masked` inputs,
- `5` extreme logit regimes across `[-1e4, +1e4]`.

**Observed verification result (`80 of 80` trials):** Both unnormalized epilogue division ($\tilde{O}^{(M-1)} / l^{(M-1)}$) and per-tile normalized running $O^{(b)}$ matched standard pre-softmax masked attention within **`maxAbsError <= 1e-12`**, with identical `mismatchCount` and `0` `NaN` outputs.

### 3.3 ES `Proxy` Zero-Read Verification on Foreign & Stale-Generation KV Blocks

Because an all-$-\infty$ masked tile is the exact identity element of the $(\max, +)$ online softmax transition ($(m^{(b)}, l^{(b)}, \tilde{O}^{(b)}) = (m^{(b-1)}, l^{(b-1)}, \tilde{O}^{(b-1)})$), checking side-array header metadata `(block_scope, alloc_generation)` before tile load allows the recurrence to branch past unauthorized blocks entirely. Wrapping every physical $K_{\text{pool}}[p]$ and $V_{\text{pool}}[p]$ subarray in ES `Proxy` `get` traps verified **`0` tensor element reads (`kvTensorReadsPerformed === 0`)** across `100%` of foreign-scope blocks (`skipped_foreign_scope_zero_kv_read`) and ABA-recycled stale-generation blocks (`skipped_stale_generation_zero_kv_read`).

### 3.4 HMAC Prefix-Cache Key Salting (`cache_salt`)

In open-weight engines with automatic prefix caching (`vLLM` `sha256_cbor` block hashing, `SGLang` RadixAttention), identical system prompts across tenants hash to the same prefix key if un-salted (`prefix_cache_hash_collision`). Mode `2 of 4` in the KV Lifecycle Explorer computes HMAC-SHA256 salted prefix digests binding server-owned `(tenantId, policyEpoch)` into every parent-chained block hash (`cache_salt`), preventing cross-tenant block sharing at lookup while retaining header-level `(scope_tag, alloc_generation)` checks as an independent second barrier.

2. **Pre-`GPU GO` Repository State (`NO GPU RUN RECORDED`):** Prior to PJ's explicit `GPU GO` window, `0 of 1` live H200 GPU runs are loaded in this repository. The workspace displays `NO GPU RUN RECORDED` (`verifierVerdict: "NOT_CONFIGURED"`, `primaryReasonCode: "NO_ARTIFACT_CONFIGURED"`).

   - **`PASS` (`2 of 73` `PASS_*` codes):** `live` or `recorded` bundle satisfies every cryptographic, manifest, rank, invariant, and sanitizer gate under its stated exclusions.
   - **`FAIL` (`57 of 73` `FAIL_*` codes):** Triggered on RFC 8259 duplicate JSON keys, canonical SHA-256 mismatch (`artifactSha256Declared !== artifactSha256Computed`), invalid Ed25519 signature, replay of a seen `run_id`, `disk_manifest` shadow/tampered files, `vLLM`/patch git SHA mismatch, runtime backend divergence, ABA `alloc_generation` regression, cross-rank disagreement (requiring `8 of 8` ranks when `tp_size = 8`), omitted exclusions, invalid `p95` sample denominators, or leaked secrets/planted values.

   - **`ERROR` (`4 of 73` `VERIFIER_ERROR_*` codes):** Returned on unreadable input paths, malformed CLI flags, or invalid `trust-root.v1` files.
4. **Zero-Echo Secret & Planted-Value Sanitization (`31 of 31` Mutation Campaigns Verified Offline):** Carbon 3's sanitizer scans `100%` of proof JSON fields, command receipts, and `RUN_DIR` logs against credential patterns and forbidden planted markers (`--forbidden-strings-file`).
