## 4. Operator Protocol to Record Tier 3 (Live Gemini) & Tier 4 (Public Deploy)

1. **Recording Tier 3 (`Observed with Live Gemini`):**
   - Configure `GEMINI_API_KEY` (server-side environment only; never committed) and `GEMINI_MODEL` (for example `gemini-2.5-flash`) from the hackathon Google Cloud project.
   - Run `ALLOW_LIVE_GEMINI=1 npm run test:live` (`tests/live/live-gemini.smoke.test.ts`).
   - Update Column 3 in Section 2 above with the observed `GEMINI_MODEL`, UTC timestamp, paired structural verdicts (`cross_tenant_context_transmitted` vs `foreign_context_withheld_before_gemini`), and latency/retry counts.
2. **Recording Tier 4 (`Deployed Publicly`):**
   - Deploy via AI Studio export or Cloud Run (`gcloud run deploy vervain-context-firewall --source . --region us-central1 --allow-unauthenticated --set-env-vars DEMO_MODE=live,NODE_ENV=production,GEMINI_MODEL=gemini-2.5-flash` with secret-mounted `GEMINI_API_KEY` and `SESSION_SECRET`).
   - Verify `/healthz`, `/readyz`, clean-browser paired proof execution, receipt export, chain verification, and zero key presence in browser DevTools, then record the public URL and commit SHA in Column 4 above and in `BUILD_PROOF.md`.
